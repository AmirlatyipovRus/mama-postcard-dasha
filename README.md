# Мама, это для тебя

Интерактивная открытка на React, TypeScript и Vite. Все иллюстрации, шрифты и тихая инструментальная мелодия входят в сборку. Прогресс сохраняется в браузере получателя.

## Локальный запуск

Установите Node.js 22.12+ и выполните:

```sh
npm ci
npm run dev
```

Для проверки с телефона в той же сети выполните `npm run dev -- --host 0.0.0.0` и откройте на смартфоне адрес Network из терминала.

## Персонализация

В `src/config/greeting.ts` находятся обращение, подпись, вступление, девять записок, финальное письмо, настройки лепестков и музыки. Сохраняйте уникальные идентификаторы записок.

Положите семейный снимок в `public/images/mom-photo.jpg`. При отсутствии снимка в рамке появится цветочная иллюстрация. Фото сохраняет свои пропорции.

Музыка по умолчанию находится в `public/audio/soundtack.mp3`. Чтобы использовать свой MP3, положите его в `public/audio/background.mp3` и замените значение `musicPath` на `./audio/background.mp3`. Для бесшумной открытки задайте `enableMusic: false`.

## Сборка и публикация

`npm run build` проверяет типы и собирает статические файлы в `dist/`. Команда `npm run preview` запускает локальный просмотр сборки.

Загрузите содержимое `dist/` в корневой каталог сайта Nginx или опубликуйте эту папку на статическом хостинге. Для GitHub Pages используйте `dist/` как Pages artifact. Относительные пути поддерживают размещение в подкаталоге. При смене адреса замените абсолютный URL `og:image` в `index.html` и пересоберите сайт. Все включённые фото и аудио будут доступны посетителям по ссылке.

Снимки основных экранов находятся в папке `screenshots/`.
